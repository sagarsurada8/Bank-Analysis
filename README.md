# Banking Analytics Project

## Project Overview
An end-to-end Banking Analytics project to analyze
customer transactions, debit and credit activities,
and banking performance.

## Tools Used
- Microsoft Excel
- SQL
- Power BI
- Tableau

## Project Files
- Excel: Data analysis and dashboards
- My SQL: Banking analytics queries
- Power BI: Interactive dashboards
- Tableau: Data visualizations
- Report: Project documentation and presentation
